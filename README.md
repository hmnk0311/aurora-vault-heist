Aurora Vault Heist is an original top-down heist game played in a desktop browser. One thief crosses the Meridian Trust bank floor on three nights: slip past patrol guards with vision cones and sweeping security cameras, lift the keycard from the office, hack the laser terminal in the security room (or crawl the vent duct), crack the vault door, steal the Aurora Diamond and reach the getaway van before the alarm meter fills. Tools cost you: an EMP blinds the cameras but surges the alarm, and a decoy coin pulls a guard off his patrol. Shadow carpets and tiptoeing slow how fast you are spotted, several routes cross every room, and a quiet escape pays a ghost bonus.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Move with WASD or the arrow keys, hold Shift to tiptoe, hold E to hack and crack, X for EMP, Q for a decoy coin, R to retry. To hand the game in the way the grader does: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
